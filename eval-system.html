软件实训 · 智能评价系统 v2.0.0

以 AI 重塑软件实训评价

中国软件杯 2026 · 参赛作品 · 开发文档 v2.0

四端角色 维度级并行评审 RAG 知识增强 语义指纹查重 校企协同 国产化部署

系统概览

系统面向软件实训教学场景，覆盖「教师布置任务 → 学生提交成果 → AI 维度级评审 → 教师复核 → 企业协同评价」全流程。前端为 Vue3 单页应用，按学生、教师、企业、管理员 四套角色布局组织页面；后端为 FastAPI 分层服务；数据层支持 SQLite / MySQL / PostgreSQL 多数据库与三级向量存储后端，可按环境平滑切换。

核心创新

  1. 维度级并行评审：多智能体按评价维度并行打分，自洽性采样、结构化输出与确定性加权聚合，评分轨迹全程留痕。
  2. 元评审与教师复核：置信度模型加硬触发复核条件，低置信结果自动进入教师复核工作流。
  3. RAG 知识增强评价：任务知识库与混合检索机制，把评分标准与课程资料注入评审上下文。
  4. 文件级语义指纹可信评价：多级匹配检测雷同提交，任务版本隔离，疑似雷同转人工复核。
  5. 三端 AI 助手：统一 Agent 骨架与意图路由，FunctionCalling 工具循环配四层安全防护。
  6. Agentic 练习计划：从薄弱维度出发，Planner-Executor 循环主动出题、批改并留痕。
  7. 实时进度与用量监控：SSE 事件总线推送评价进度，LLM 用量按功能与模型聚合治理。
  8. 国产化适配：开发环境、Docker、龙芯离线部署三套环境共用同一套后端代码。

业务流程与角色

学生以学号、教师以工号、企业以企业账号、管理员以 admin 登录；密码采用 PBKDF2-SHA256 哈希存储，管理员另有三重验证。企业注册后经管理员认证，接受教师发起的 课程级邀请，查看脱敏提交并评分，在报告中心查看能力画像。

AI 智能评价引擎

学生创建提交后，后台异步执行评价流水线，按阶段推进并通过事件总线发布进度事件，前端 SSE 实时呈现。v2.0 将单次大模型评价升级为维度级并行评审：按评价维度拆分为多个评审 智能体并行打分，再经自洽性采样与加权聚合得到最终成绩，全程留痕可回溯。

四端功能展示

学生端

AI 学习助手按任务辅导、作业改进、代码文档评审等模式提供辅导，可调用工具查询成绩、 生成雷达图；评价完成且存在薄弱维度时，助手主动生成练习计划，AI 批改并留痕。

教师端

AI 洞察中心汇总班级得分矩阵、薄弱学生预警与成长画像；AI 教学助手支持智能出题与 批量评语；三栏评阅让提交原文、AI 评审与教师复核同屏对照。

企业端

企业上传脱敏项目案例进入模板库供教师参考，双向沟通任务需求；报告中心按任务聚合 企业评分维度画像与学生排名，呈现企业视角下的能力表现。

管理员端

全局统计与账号管理之外，LLM 用量监控按功能与模型聚合 Token 用量、缓存命中率与调用 明细；系统配置热加载让修改即时生效，密钥类配置脱敏展示。

系统部署

开发环境、Docker 与龙芯离线部署三套环境共用同一套后端代码：开发环境以 SQLite 起步、无需安装数据库；Docker 通过 Compose 叠加文件切换多数据库变体，用于标准平台 生产；龙芯离线安装包自包含，满足国产化环境要求。
